# CourseBox deployment

GitHub stores the source code. It does not run the FastAPI server, so a public
URL requires a hosting service.

## Deploy from GitHub with Render

1. Push this repository to GitHub.
2. Open `https://dashboard.render.com/` and sign in with GitHub.
3. Choose **New +** -> **Blueprint**.
4. Select the `CourseBox` repository and the `render.yaml` file.
5. Create the service and wait for the first deploy to finish.
6. Open the generated `https://....onrender.com/` URL and share it.

The Blueprint binds Uvicorn to `0.0.0.0` and uses Render's `$PORT`, which is
required for a web service. The administrator username is `admin`; the initial
password is generated by Render and must be read from the service environment
settings before logging in.

The free Render filesystem is temporary. Uploaded files and SQLite data can be
lost after a restart or redeploy. Use a persistent disk or an external database
and file store for a real production deployment.

## Deploy with Docker

```powershell
docker build -t coursebox .
docker run --rm -p 8000:8000 coursebox
```

Open `http://127.0.0.1:8000/` locally. To share it on the same LAN, use the
host computer's LAN address, for example `http://172.24.136.216:8000/`, and
keep the container running.

## Local Windows startup

```powershell
.\scripts\start.ps1 -BindHost 0.0.0.0 -Port 8000
```

Then share `http://<your-LAN-IP>:8000/` with users on the same network. This
does not work when the network blocks device-to-device traffic.
